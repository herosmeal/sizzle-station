Sizzle Station is a tiny top-down cooking game: run one busy kitchen for a day — pick ingredients from the bins, chop them at the board, cook them on the stove, plate each dish on the counter and serve it at the window before its order expires. Orders stack up, timers run down, combos build, and three expired orders end the day. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, press E to use the nearest station, or click a station to walk there and use it. P pauses, M mutes.
